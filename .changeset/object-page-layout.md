Add the Object Page layout: `ObjectPage`, `ObjectPageHeader` and `ObjectPageSection`. `ObjectPage` fills the height of its parent and has a single scroll container (focusable, so a text-only page can be scrolled from the keyboard) that holds the header and the sections; the header scrolls away with the content. The scroller pads its bottom with `--rop-keyboard-inset`, so a focused `Field` in the last section can be scrolled above the virtual keyboard, and an empty slot below it is reserved for the footer. Without a parent height the page grows and the document is the single scroller. `ObjectPageHeader` takes `title` (wraps, never truncated), `subtitle`, `status` and `actions` (below the title on a narrow screen); its title is an `h<headingLevel>` (`headingLevel` 1-4 on `ObjectPage`, default 1) and the sections' titles are one level below. `ObjectPageSection` is a `<section id aria-labelledby>` (a `region` named by the text of its title) with `scroll-margin-top: var(--rop-object-page-sticky-offset, 0px)` and a body that scrolls horizontally on its own. Sections register `{ id, title }` in the page in DOM order (also when wrapped by consumer components, conditional, renamed or reordered); a duplicate id warns in development; a section or header outside an `ObjectPage` throws in development. Exports the types `ObjectPageProps`, `ObjectPageHeaderProps` and `ObjectPageSectionProps`.
