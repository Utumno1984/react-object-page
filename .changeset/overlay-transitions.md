'@react-object-page/core': minor
---

`Dialog` and `Sheet` now animate: the backdrop fades and the panel fades and scales in (`Dialog`) or slides in from its edge (`Sheet`), and both animate out before the nodes are removed (160 ms, `cubic-bezier(0.2, 0, 0, 1)`). The durations come from new tokens `--motion-rop-overlay-duration` / `--motion-rop-overlay-easing`; the animations are keyframes (`rop-overlay-*`, `rop-modal-*`, exposed as `--animate-rop-*`), and they are applied only under `motion-safe:`, so with `prefers-reduced-motion: reduce` there is no animation at all and the panel appears and disappears at once, as before.

Focus handling is unchanged in behaviour but now follows the real unmount: the focus trap is released as soon as the state turns closed, while the focus returns to the opener in the frame after the exit animation has finished (not in the middle of it). `useReturnFocus` gets an optional `skipWhen` callback, used by the modals so that a delayed return does not steal the focus from another modal opened in the meantime (a "close this one, open that one" chain). While exiting, the whole panel is `inert`: the backdrop does not intercept clicks, nothing in it is focusable, and the page behind can be used at once; opening it again (click on the opener) during the exit reuses the same panel, moves the focus back inside it and keeps the original opener. If the exit animation never ends (paused, or keyframes missing) the panel is removed after its duration plus 500 ms, so the page cannot stay locked.

Known limits: an Escape pressed while a nested dialog is still leaving (under ~160 ms) is consumed by it, the next one closes the outer dialog; the "Esci senza salvare" path of `useDirtyGuard` removes the confirmation without an exit animation (the action that follows may unmount the page). The animated `scale` / `translate` properties are used instead of `transform`, so the `Dialog`'s centring is untouched. No new public component API (the animation is not configurable from the consumer in this release); the compiled `styles.css` now contains five top-level `@keyframes rop-*` rules, which cannot be placed in a layer, and the motion tokens add a few hundred bytes to the per-import bundle sizes (`tokens.css` is read by `cn`).
