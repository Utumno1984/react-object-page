New `ListReport`, the simple List Report floorplan: a `Title` with the result count (`(n)`, and `(n di m)` when a pill or the search hide some rows; format in `labels.count`), an `actions` slot, the `ListReportFilterBar` and the `ListReportTable` in one flex column (`height: 100%`, `min-height: 0`) with a single scroller: title and bar stay put, only the table container scrolls and its header sticks. In the normal flow of the document (a parent without a height) it does not collapse: the table grows with its rows and the page scrolls. The table is named by the text of the title through `aria-labelledby` (a title with an icon still names it by its text; two reports on one page have distinct ids); the count is part of the heading and is not a second live region (the table's own region is the only one). "Azzera filtri" works with no wiring (`table.clearFilters()`) and puts the focus on the search box, or the first pill when there is none; a custom `onClearFilters` replaces that default. `status`, `errorMessage`, `onRetry`, `loadingRowCount` and `labels` reach `ListReportTable` unchanged; `filtersLabel`, `searchLabel` and `showSearch` reach the bar (without pills and without search the bar is not rendered). The count keeps its box (invisible) while loading without rows and on error, so the header never moves. Props: `title`, `titleLevel`, `table`, `actions`, `status`, `errorMessage`, `onRetry`, `onClearFilters`, `loadingRowCount`, `labels`, `filtersLabel`, `searchLabel`, `showSearch`, `className` and the root's HTML props. Bundle budget: new `ListReport` entry; the other entries moved up by about 20-25 B gzip, the cost of the extra module's import statements in the per-export measurement.
