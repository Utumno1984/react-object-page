`useObjectPageForm`: new `validate?: (values) => Partial<Record<keyof Values, string>>` option and `fieldErrors` return value, distinct from `saveError`. `save(handler)` calls `validate` synchronously on the current values before the handler; if the result has any key, `fieldErrors` is set, the handler is not called, `isSaving` is untouched and `save` resolves `false`. Without `validate`, behavior is unchanged and `fieldErrors` is always `{}`. `fieldErrors` is cleared as a whole by `setValue`, `setValues`, `reset` and a successful save. The hook still never touches the DOM (SSR-safe). New `useFocusFirstInvalidField({ containerRef, fieldErrors })` (pure DOM/React, independent of the form hook): when `fieldErrors` goes from empty to non-empty it finds `[name="<key>"]` controls inside the container, picks the first in document order (`compareDocumentPosition`, not key order), scrolls it to the center and focuses it; with no matching control it does nothing and logs one `console.error` in development. Exports `useFocusFirstInvalidField` and `UseFocusFirstInvalidFieldOptions`.
